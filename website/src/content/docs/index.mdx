  <section class="landing-boundaries" aria-labelledby="boundaries-title">
    <div class="section-heading">
      <div class="section-kicker">02 / OWNERSHIP</div>
      <h2 id="boundaries-title">One control plane. Clear boundaries.</h2>
      <p>Lasso coordinates the workspace without becoming a second build system or a second agent runtime.</p>
    </div>

    <div class="boundary-grid">
      <article class="boundary-card boundary-card--runtime">
        <span class="boundary-index">01 / RUNTIME</span>
        <h3>Agent runtime</h3>
        <p>Owns the live goal, plan, session, review, and memory. Codex is the baseline; followers use thin adapters.</p>
        <code>goal · plan · review</code>
      </article>
      <article class="boundary-card boundary-card--lasso">
        <span class="boundary-index">02 / LASSO</span>
        <h3>Lasso workspace</h3>
        <p>Owns project identity, stable checkout bootstrap, task-worktree convention, modules, and exceptional work items.</p>
        <code>registry · worktrees · modules</code>
      </article>
      <article class="boundary-card boundary-card--project">
        <span class="boundary-index">03 / PROJECT</span>
        <h3>Owning project</h3>
        <p>Owns its build, test, deploy, secrets, service health, and language-specific commands.</p>
        <code>build · test · deploy</code>
      </article>
    </div>
  </section>

  <section class="landing-extensions" aria-labelledby="extensions-title">
    <div class="section-heading">
      <div class="section-kicker">03 / EXTENSION MODEL</div>
      <h2 id="extensions-title">Add capabilities without forking the core.</h2>
      <p>Modules are versioned capability packs. They extend the workspace through conventions, checks, skills, hooks, and scripts.</p>
    </div>

    <div class="extension-flow" aria-label="Lasso module installation flow">
      <div class="extension-node">
        <span class="extension-label">CATALOG</span>
        <code>modules/catalog.toml</code>
        <small>available packs</small>
      </div>
      <span class="extension-arrow" aria-hidden="true">→</span>
      <div class="extension-node extension-node--command">
        <span class="extension-label">INSTALL</span>
        <code>lasso module add &lt;id&gt;</code>
        <small>deterministic state change</small>
      </div>
      <span class="extension-arrow" aria-hidden="true">→</span>
      <div class="extension-results">
        <span><code>.lasso/modules/</code><small>payload</small></span>
        <span><code>lasso.lock.toml</code><small>version pin</small></span>
        <span><code>plugins/lasso-&lt;id&gt;/</code><small>runtime surface</small></span>
      </div>
    </div>

    <div class="extension-types">
      <article>
        <span>CONVENTION</span>
        <strong>Teach the workspace</strong>
        <p>Language packs and project rules that merge into the workspace guidance.</p>
      </article>
      <article>
        <span>CAPABILITY</span>
        <strong>Check the workspace</strong>
        <p>Deterministic scripts and contracts such as documentation indexes.</p>
      </article>
      <article>
        <span>PLUGIN</span>
        <strong>Give agents a workflow</strong>
        <p>Shared skills, hooks, and thin runtime manifests for agent-facing behavior.</p>
      </article>
    </div>
