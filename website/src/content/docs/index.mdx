  <section class="landing-features" aria-labelledby="features-title">
    <div class="section-heading">
      <div class="section-kicker">02 / CAPABILITIES</div>
      <h2 id="features-title">A small, durable layer for a large workspace.</h2>
      <p>Keep coordination visible and repeatable without turning the workspace into another build system.</p>
    </div>

    <div class="feature-grid">
      <article class="feature-card feature-card--featured">
        <div class="feature-index">A</div>
        <h3>Project registry</h3>
        <p>Identity-only TOML entries make every repository discoverable without copying its toolchain into the workspace.</p>
        <code>project-defs/*.toml</code>
      </article>
      <article class="feature-card">
        <div class="feature-index">B</div>
        <h3>Stable checkouts</h3>
        <p>Bootstrap ordinary clones and create task worktrees with predictable paths, so agents can move with confidence.</p>
        <code>lasso setup</code>
      </article>
      <article class="feature-card">
        <div class="feature-index">C</div>
        <h3>Installable skills</h3>
        <p>Package judgment-heavy workflows as modules that follow the Codex baseline and adapt cleanly to other runtimes.</p>
        <code>lasso module add</code>
      </article>
      <article class="feature-card">
        <div class="feature-index">D</div>
        <h3>Durable handoffs</h3>
        <p>Keep cross-session coordination in work items while live goals, plans, and task state stay with the agent runtime.</p>
        <code>work-items/</code>
      </article>
    </div>
  </section>
