# Lasso documentation site

Astro + [Starlight](https://starlight.astro.build/) site published to GitHub Pages.

```bash
cd website
corepack pnpm install
corepack pnpm run dev      # http://localhost:4321/lasso/
corepack pnpm run build    # → dist/
```

Production URL: https://dravengarden.github.io/lasso/

Content lives in `src/content/docs/`. Config: `astro.config.mjs`.
