# Bug recipe

Create `investigation.md` when reproduction evidence, eliminated hypotheses, or
root cause must survive beyond the current thread. A small obvious bug usually
needs no durable document.

Use `assets/bug.md`. Preserve observed facts separately from hypotheses. Record
the smallest reliable reproduction, actual versus expected behavior, evidence,
root cause once proven, and the regression proof. Do not store a speculative
fix as if it were diagnosis.
