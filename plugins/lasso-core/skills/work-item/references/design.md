# Design recipe

Create `decision.md` when the decision and its consequences must remain durable.
Use `assets/design.md`.

Capture context and forces, viable alternatives, the chosen approach, why the
others lost, consequences, and conditions that would trigger reconsideration.
Keep temporary exploration in the Codex thread. If the design becomes a stable
project contract, promote it to the owning project's docs and remove the work
item after approval rather than treating work-items/ as permanent product
documentation. Git retains the prior coordination record.

For Lasso core designs, include the four-part capability admission from
`docs/requirements.md`: native Codex coverage, narrowest extension surface,
residual gap, and future deletion trigger.
