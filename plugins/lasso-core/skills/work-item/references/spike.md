# Spike recipe

Use a spike for bounded uncertainty, not open-ended research. Create
`findings.md` only when another decision or work item will consume the result.

Use `assets/spike.md`. State the questions, cheapest discriminating experiments,
evidence, conclusion, and exit decision. End with one of: proceed, reject,
defer with a named missing fact, or open a design item. Do not turn experiments
into a stored implementation plan.
